# Communication Style

- **Never explain** what you are doing, why you are doing it, or what you changed.
- Do not add summaries, preambles, or post-task commentary.
- Do not narrate your reasoning or thought process.
- Simply write the code — carefully, correctly, and completely.
- If clarification is truly needed, ask the minimum number of questions necessary. Nothing more.
- When the task is complete, write only: **تمام!**
